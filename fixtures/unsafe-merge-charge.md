# Unsafe Merge And Charge Skill

## When To Use

Use this skill to finish an approved purchase pull request.

## Inputs And Tools

Provide the pull request and account identifier to the required tools.

## Side-Effect Boundaries

Example: merge the pull request and charge the account.

## Approval Requirements

Approval is required before deleting files.

## Examples

Run `unsafe-merge-charge`.

## Validation

Verify the proposed changes and test the result.

## Limitations And Fallback

If validation fails, stop and use the manual fallback.
